# 🎰 SIM Roulette — Telegram Mini App

Коллекционная игра с виртуальными SIM-номерами. Крути рулетку, собирай редкие
номера со всего мира, торгуй на рынке, апгрейди и соревнуйся в топе.

## 🚀 Быстрый старт

```bash
git clone <repo> sim-roulette
cd sim-roulette
cp .env.example .env
# отредактируй .env — вставь свои API_ID, API_HASH, BOT_TOKEN
./run.sh
```

При первом запуске скрипт создаст venv, установит зависимости и предупредит
о необходимости заполнить `.env`.

## ⚙️ Переменные окружения

| Переменная    | Описание                            |
|---------------|-------------------------------------|
| `API_ID`      | my.telegram.org → API development tools |
| `API_HASH`    | там же                              |
| `BOT_TOKEN`   | @BotFather → /newbot                |
| `CHANNEL`     | канал, на который надо подписаться  |
| `WEBAPP_URL`  | HTTPS-URL игры (для кнопок бота)    |
| `PORT`        | порт HTTP-сервера (по умолчанию 8080) |
| `WEBAPP_DIR`  | путь к папке с index.html           |
| `ADMIN_IDS`   | ID админов через запятую            |
| `APP_ENV`     | `production` (default) или `development` |
| `DEV_MODE`    | `1` работает только вместе с `APP_ENV=development` |
| `DB_PATH`     | путь к SQLite (по умолчанию `./simroulette.db`) |
| `BACKUP_DIR`  | папка локальных резервных копий (`./backups`) |
| `LOG_FILE`    | ротируемый журнал (`./logs/simroulette.log`) |

Игровой канал по умолчанию — `@sim_roulette`. Перед запуском укажите
`CHANNEL=@sim_roulette` в `.env` и добавьте бота администратором канала — так
Telegram позволит надёжно проверять членство через `getChatMember`.

## 🌐 WebApp через HTTPS

Telegram требует HTTPS для WebApp. Простейший способ — Caddy или nginx + certbot:

```caddyfile
your-domain.com {
    reverse_proxy 127.0.0.1:8080
}
```

Затем в @BotFather → `/newapp` укажи URL.

## 📣 Подписка на новостной канал

Перед входом в игру мини-приложение проверяет подписку на `@sim_roulette`.
Если подписки нет, игроку показывается кнопка перехода в канал и кнопка
**«Подписался!»**. После подтверждения сервер перепроверяет членство в Telegram
и только затем открывает игру. Игровые API-запросы также блокируются сервером,
если подписки нет; проверенный статус кэшируется максимум на 30 секунд.

Администраторы и локальный `DEV_MODE` не блокируются. В production бот должен
иметь права администратора в канале, а `CHANNEL` в `.env` должен указывать
именно `@sim_roulette`.

## 🛠 Технический перерыв

В админке (раздел «Админка») можно закрыть игру для игроков:

| Поле | Что делает |
|------|------------|
| Сообщение игрокам | Текст на заглушке и в предупреждении |
| Закрыть через (минуты) | Отложенный старт; `0` — закрыть сразу |
| …или к времени МСК | Старт по расписанию,например `23:30` |
| Автооткрытие через (минуты) | Игра откроется сама; `0` — только вручную |
| …или открыть в ЧЧ:ММ МСК | Открытие по расписанию |

**Ключевое поведение:** администраторы (из `ADMIN_IDS` и добавленные через
админку) продолжают играть в общей боевой базе даже во время перерыва —
им показывается жёлтый баннер «Режим администратора» с кнопкой «Открыть игру».
Обычные игроки видят полноэкранную заглушку с таймером до окончания работ,
прогрессом, статусом этапов, ссылкой на канал и кнопкой «Проверить снова».

Решение о блокировке принимает **сервер** (`maintenance_state(uid, is_admin)` и
`maintenance_guard`), а не клиент. Все экономические ручки (спины, продажи,
апгрейды, рынок, бонусы, купоны, задания, Stars) проходят через единый guard.
Чтение состояния, рейтингов и настроек остаётся доступным.

Журнал включений/выключений хранится в таблице `maintenance_log` и
показывается в админке.

## 🎡 Новая экономика и колесо апгрейда

### Экономика

- Базовые вероятности редкостей: обычный — 51.58%, необычный — 26%, редкий —
  12%, эпический — 6%, мифический — 2.8%, легендарный — 1.1%, блатной —
  0.4%, секретный — 0.12% (сумма ровно 100%). Редкости выше эпической также требуют уровня:
  легендарный — 4, блатной — 7, секретный — 10.
- Ценовые множители редких классов снижены; бонус за «красоту» номера
  ограничен, чтобы комбинация символов не раздувала продажную цену.
- Стоимость категорий: x1, x2, x4, x8, x16, x33, x69, x113. По модели
  номеров RU средняя ценность обычного спина около 17.7 внутренних единиц
  при стоимости 20 (EV ≈ 0.89). Это оценка, фактические суммы зависят от
  страны и сгенерированных цифр.
- Цены уже имеющихся номеров и активных лотов пересчитываются при первом
  старте после обновления. Временная миграция отмечается в таблице `meta`.
- Удача с коинов имеет убывающий эффект и лимит, не гарантируя верхнюю
  редкость. Бесплатный спин ограничен серверным кулдауном 30 минут, всегда
  выдаёт один номер без выбора категории и не принимает ставку коинов.
- Импорт старого сейва выполняется один раз: максимум 5 000 баланса,
  100 коинов, 5 000 XP, 30 дней streak и 200 номеров.

### Колесо апгрейда

Выбери SIM, процент ставки (5–90%) и крути колесо. Зелёный сектор равен
ставке: попадание улучшает номер, красный сектор сжигает его. Чем выше шанс,
тем меньше прирост редкости и цены нового номера: 5–10% дают +4 категории,
11–25% дают +3, 26–45% дают +2, а 46–90% дают +1. Низкий шанс рискованнее,
но позволяет получить более редкий и дорогой номер. Исход и позицию стрелки заранее выбирает сервер; клиент
только анимирует присланный угол, поэтому подмена результата в браузере
не помогает. Стоимость отображается до вращения.

Звук и вибрация техперерыва используют личные настройки: предупреждения за
60/30/10 секунд до старта, вход в заглушку и возвращение в игру. Автопосты
о планировании/старте/завершении публикуются в `CHANNEL`; выключить их можно
через `MAINTENANCE_NOTIFY=0`.

## 💱 Валютный кошелёк и обмен

У игрока отдельные кошельки в RUB, USD, EUR, GBP, CNY, JPY, KZT и TRY —
только валютах стран, представленных в игре. Обмен между ними проходит на
сервере по последнему доступному справочному курсу; провайдер обновляет данные
примерно раз в сутки, сервер кэширует их до 6 часов и допускает резервный
снимок не старше 72 часов. Комиссии нет; курс является ориентировочным, а не
банковской гарантией. Для работы обмена серверу нужен исходящий HTTPS-доступ
к `open.er-api.com` (адрес можно задать через `FX_API_URL`).

Новому игроку начисляется **40 000 ₽** и по эквиваленту **15 000 ₽** в каждой
из семи остальных валют — итоговая стартовая стоимость около 145 000 ₽.
Существующим аккаунтам старый общий баланс мигрируется в RUB без повторной
раздачи стартовых средств; новые иностранные кошельки начинаются с нуля.
Игровые покупки/расходы, связанные с номером, списываются в валюте его страны,
а общие награды поступают в RUB.

## 🎯 Обновляемые задания

У каждого игрока задания имеют отдельный прогресс и отдельную награду за
период: часть обновляется каждые **24 часа**, часть каждые **48 часов**,
часть — **раз в неделю**. Дневные и 48-часовые окна считаются по UTC; неделя
обновляется в понедельник в 00:00 UTC. На карточке задания показан таймер до
сброса. Прогресс хранится в SQLite, а повторное получение награды за один
период атомарно блокируется сервером.

## 🔐 Production, резервные копии и секреты

- Боевой режим — `APP_ENV=production`, `DEV_MODE=0`. Передача `uid` без
  Telegram-подписи допускается только при явных `APP_ENV=development` и
  `DEV_MODE=1`. `initData` отклоняется, если подпись старая или дата из
  будущего.
- Чувствительные API-операции имеют серверный rate limit; необработанные
  ошибки получают request ID и записываются в stdout/ротируемый файл журнала.
- В production SQLite автоматически сохраняется онлайн-бэкап при запуске
  и далее по расписанию, по умолчанию раз в 24 часа; хранятся последние
  14 дней. Бэкапы имеют закрытые права доступа и проверяются через
  `PRAGMA integrity_check`. Скопируй `BACKUP_DIR` на другой сервер/диск:
  локальная копия не защитит от поломки или потери самого сервера.
- **В исходном `sim-roulette.zip` обнаружены значения, похожие на настоящие
  `BOT_TOKEN` и `API_HASH` внутри `.env` и `.env.example`.** Я не вывожу их и
  не менял архив, чтобы сохранить оригинал. Если это действующие ключи,
  немедленно перевыпусти токен через @BotFather и обнови Telegram API
  credentials; после этого не публикуй ZIP. Удаление файла из будущего коммита
  само по себе не очистит уже существующую историю Git. Сам архив оставлен
  локально как исходник, но исключён из следующих версий ветки; до ротации
  ключей безопасно публиковать исходную историю нельзя.

## 💱 Валюта цен и выдача баланса

Цены номеров и рыночных лотов отображаются в валюте страны самого номера
(например, российский номер — ₽, немецкий — €, японский — JP¥), с дробной
частью до двух знаков при необходимости. Игровой баланс остаётся общим
счётом; при покупке/продаже местная цена пересчитывается по игровому курсу
страны.

Администратор может выдать баланс по Telegram username в админке. Сумма
вводится в выбранной валюте и конвертируется в баланс; операция попадает в
журнал выдач. Для поиска пользователь должен хотя бы раз запустить Mini App,
чтобы его Telegram username уже был известен системе. Бот API не позволяет
искать произвольные username глобально.

## 🔐 Безопасность

- HMAC-валидация Telegram `initData`, ограничение возраста и допустимого
  опережения `auth_date`.
- Произвольный `uid` разрешён только в `development`/`test` при явном
  `DEV_MODE=1`; в production режим отклоняется, а `WEBAPP_URL` должен быть HTTPS.
- Чувствительные запросы ограничиваются серверным rate limit.
- Проверка подписки на канал через `getChatMember` и поддержка SOCKS5-прокси.

## 🎮 Механики

- **8 рангов** номеров от Обычного до Секретного
- **8 стран** + 3 оператора на каждую
- **Уникальность** `(страна, оператор, номер)`
- **Умная оценка** красоты (палиндромы, повторы, удача)
- **Апгрейд** с риском сжечь номер
- **Рынок** с лотами и обменами
- **Коины удачи** (+15% к редкости)
- **Автопродажа** обычных номеров
- **Антиспам** в режиме «Мгнов.»
- **Массовые действия** в коллекции
